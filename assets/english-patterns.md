## 高频陷阱清单（§10.3 C1—C10，速查用）

| # | 陷阱 | 错误 → 正确 |
|---|---|---|
| C1 | 冗余范畴词 | "the situation of chaos" → "chaos" |
| C2 | 万能动词 | "make a decision" → "decide" |
| C3 | 抽象名词堆砌 | "the realization of the importance of stability" → "he realized stability mattered" |
| C4 | 过度连接词 | "Firstly… Secondly… Moreover…" → 每段连接词不超过 1 个 |
| C5 | 直译成语/典故 | "talking about war on paper" → "he had read every military manual, but had never commanded an army" |
| C6 | 被动堆砌 | "It was decided by the court that…" → "The court decided…" |
| C7 | 修饰语前置过长 | 拆成两句 |
| C8 | 时态混乱 | 叙事主体过去时；分析/现在时对话 |
| C9 | 伪正式表达 | "in order to" → "to"；"at this point in time" → "now" |
| C10 | 中文语序残留 | 状语从句后置而不前置 |
