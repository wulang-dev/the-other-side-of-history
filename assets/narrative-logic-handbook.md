# 叙事逻辑转换手册（N1—N10 正反样例库）
# PRD v13.0 §9.5 + §9.8

> **定位**：本手册是"判断校准器"，不是"正确答案库"。用于 Gate 3 审查时对照检查。
> **使用方式**：Gate 3 审查时，人类至少对照样例库检查 2 个最相关 N 项，写明"对照 Nx 正例/反例，本段属于哪一侧、为什么"。
> **反模板化纪律**：禁止 AI 直接复制样例句式生成脚本；A4 遮名测试同时检测脚本与样例库文本相似度（§9.5）。
> **演进**：每完成 5 条视频，回填 1—2 组新的正反样例。

---

## N1 道德史观
| 类型 | 示例 |
|---|---|
| 正例（转换恰当） | "史料记载他是'酷吏'。问题不在于贴标签，而在于当时官僚考核体系奖励什么、记录成什么。" |
| 反例一（转换不足） | "他是个暴君，因为他很残暴。" |
| 反例二（转换过头） | "整部中国官僚史就是一部酷吏的狂欢。" |

## V1—V10 价值观红线（§9.3，简要列表）

| # | 红线 | 检查关键词/语义信号 |
|---|---|---|
| V1 | 不美化专制 | "必要的秩序"、"英明的独裁"、"历史的必然" |
| V2 | 不娱乐化暴力 | 暴力段落无画面渲染；数字后跟承受者 |
| V3 | 不漠视个体生命 | 避免把数十万死亡简化为数字 |
| V4 | 不性别歧视 | 避免复制史书中厌女语言 |
| V5 | 不民族主义化 | "五千年不断"、"文明优越"等框架 |
| V6 | 不宗教嘲讽 | 不嘲讽任何宗教的历史角色 |
| V7 | 不碰当代政治 | 无当代影射、类比、映射 |
| V8 | 不为历史人物做道德辩护 | "他虽然…但是…"这类转折辩护 |
| V9 | 不做道德相对主义 | "当时就是这样"消解呈现边界 |
| V10 | 不制造虚假争议 | "被掩盖的真相"、"历史骗了你" |
