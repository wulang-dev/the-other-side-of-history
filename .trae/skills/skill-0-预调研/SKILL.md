# skill-0 预调研（Preflight Research）
# PRD v13.0 §6 + §23

---

## 定位
预调研在 Gate 1 之前执行，目的是让人类在选人、选问题框架、写候选标题和缩略图、评估叙事逻辑与价值观风险、预判留存结构和系列格式时有依据。输出 `preflight-research.md`，人类读完后再做 Gate 1 裁决。

## 前置条件
- 人类提供 1—3 个候选人物名（可留空，由 AI 给出建议）
- 人类确认可用数据源等级（直连 / 降级 / 纯人工）

## 输入
- `candidate_figures`（必填，1—3 个中文名）
- `candidate_question_frames`（可选，可留空）
- `stage`（必填：开篇期 / 成长期 / 成熟期）
- `data_source_level`（必填：直连 / 降级 / 纯人工）

## 输出
- `episodes/{slug}/preflight-research.md`（十部分结构）
- 文件 frontmatter：`gateStatus: "pending"`
- Gate 1 未通过前，下游 Skill 不得执行

### preflight-research.md 十部分结构
| # | 部分 | 内容 |
|---|---|---|
| 1 | 史料可得性 | 正史、方志、私人文集、考古材料；"已知/空白"标注 |
| 2 | 欧美认知度 | Google Trends / 英文维基 / YouTube 同类 / 流行文化痕迹；受限数据源标注"降级估算" |
| 3 | 竞争分析与赞助兼容性 | 同类选题、差异化空间、赞助兼容性标记 |
| 4 | 问题框架与标题/缩略图建议 | 2—3 个问题框架 + 候选标题 + 候选缩略图方案 + 叙事风险 |
| 5 | 叙事逻辑与价值观风险 | N1—N10 依赖程度 + V1—V10 风险 + 边界建议 |
| 6 | 潜在争议点 | 学术界争议、评论区高争议话题预判 |
| 7 | 地图需求评估 | 是否需要 CHGIS、年份、范围、坐标查询量 |
| 8 | 风险分级 | 低 / 中 / 高 + 理由 |
| 9 | 数据源与降级记录 | 直连 / 缓存快照 / 降级估算 / 人工补充 的逐项标注 |
| 10 | 留存结构与系列格式预判 | 前 3 秒钩子、30 秒开环、60—90 秒 re-hook、代价碎片位置；可归入或新建的系列问题格式 |

## 流程
1. 输入候选人物和问题框架，确认数据源等级
2. AI 执行调研（CBDB / 正史原文 / 可直连公开数据源）
3. 受限数据源按 §19.3 降级方案处理
4. 生成 `preflight-research.md`，第 4 部分含 2—3 条候选标题和缩略图，第 9 部分记录数据源使用情况
5. **输出后立即暂停**，等待人类做 Gate 1 裁决

## 降级方案（§19.3）
| 数据源 | 直连可用性 | 降级 |
|---|---|---|
| CBDB | 通常可访问 | 本地缓存快照（每月更新） |
| 正史原文 | 通常可访问 | 本地保存的原文文本 |
| Google Trends | 受限 | 间接估算：英文维基词条长度、YouTube 同类公开播放量 |
| YouTube 公开数据 | 部分受限 | 第三方统计站点 + 人工记录 |
| 竞品分析 | 部分受限 | 本地快照 + 人工抽样 5—10 个同类视频结构特征 |

**纪律**：降级不等于跳过；降级必须标注；不引入未经授权代理。人工补充最低标准：5 个同类视频 + 2 个社群讨论 + 1 份维基评估。

## 合规
- 爬取范围：公有领域原始史料、开放数据库、明确开放许可的学术资料
- 不绕过平台访问限制
- 不使用来源不明的爬取服务
- 竞争分析只做公开信息比对，不复制他人脚本

## 成本
预调研调用文本模型约 2—5 万 token，成本约 0.5—2 元。

## 人类阻塞点
Gate 1 是人类裁决，预调研报告是材料不是决定。人类可以选择"报告建议高风险但我偏要做"，但必须在 Gate 1 记录理由，并明确叙事逻辑转换方案、价值观边界、留存结构方案。
