# skill-5 成片自检（Self-Check）
# PRD v13.0 §17 + §23

---

## 定位
成片自检发生在视觉流水线完成、人工终检之前。分两层：**自动自检**（A1—A37，机械项）+ **人工自检**（H1—H10，判断项）。自动自检输出 `self-check-report.md`，人工自检在报告上逐项签字。自检不替代人工终检。

## 前置依赖
- 粗剪成片已输出（skill-3 完成）
- SRT 字幕已上传 YouTube Studio（`subtitle_upload` 手动步骤完成）
- `voiceover-manifest.json` 已归档到 `episodes/{slug}/`
- `.env` 已配置（如使用 AI 语义扫描）

## 输入
- 成片视频文件
- `script.md`（英文旁白）
- `source-ledger.json`
- `voiceover-manifest.json`
- `timeline.json`
- SRT 字幕文件

## 输出
- `episodes/{slug}/self-check-report.md` — 含 A1—A37 自动自检结果 + H1—H10 人工自检签字栏
- 文件 frontmatter：`gateStatus: "pending"`
- 任何 **FAIL** 阻止进入人工自检

## 自动自检项（A1—A37）
执行方式：`node scripts/self-check.mjs` 逐项读取文件、计算指标、输出 PASS/FAIL/WARN。

| 编号 | 检查项 | 标准 | 失败处理 |
|---|---|---|---|
| A1 | 脚本 claim 可追溯 | 每条 known/inference 匹配 source-ledger | 阻止发布，退回 Gate 2 |
| A2 | 三幕四段完整性 | 钩子-局面-选择-代价-开放问题 | 退回 Gate 3 |
| A3 | 钩子位置 | 核心问题出现在前 5 秒 | 退回重写钩子 |
| A4 | 遮名测试 | 与近 3 集脚本因果机制/代价性质不同；与样例库文本相似度未超标 | 退回调整 |
| A5 | 色板一致性 | 全部色值在 Style Guide 范围 | 退回视觉重渲染 |
| A6 | 字体一致性 | 无书法/艺术字体 | 退回视觉 |
| A7 | 视觉模式中断频率 | 每 30—60s 一次视觉单元切换 | 补视觉中断 |
| A8 | 地图年份标注 | 每个地图镜头绑定 CHGIS 年份 | 核对地图 |
| A9 | 地图标注指向 | AI 预筛无可疑帧 | 地图修正 |
| A10 | 音频响度 | -14 LUFS 左右，峰值 ≤ -1 dBTP | 混音 |
| A11 | 语速 | WPM 150—170，波动 ≤ 10 | 重生成配音 |
| A12 | 音色一致性 | 全片 Voice ID 一致 | 重生成配音 |
| A13 | 字幕完整性 | SRT 无大量缺行 | 修复 SRT |
| A14 | 字幕时间偏差 | < 100ms | 重新对齐 |
| A15 | 专名校正 | 匹配发音词典 | 修正词典重生成 |
| A16 | 软字幕上传状态 | 长视频不烧录，SRT 作为轨道上传 | 修正发布配置 |
| A17 | AI 披露 | 简介含人类主导声明 | 修改简介 |
| A18 | 来源台账完整性 | source-ledger.json 字段齐全 | 补齐考据 |
| A19 | 版权素材 | 无来源不明素材 | 替换 |
| A20 | 文件归档 | 本集全部产物归档至 episodes | 补齐归档 |
| A21 | 叙事逻辑框架 | 非道德判断；N1—N10 无残留；绝对化密度不超标 | Gate 3 重写 |
| A22 | 价值观红线扫描 | 无 V1—V10 明确违规 | Gate 3 重写 |
| A23 | 暴力呈现边界 | 暴力侧重后果承受，数字后跟个体 | Gate 3 重写 |
| A24 | 当代政治映射 | 标题脚本无当代类比 | Gate 3 重写 |
| A25 | 可读性指标 | FK 7—9；句长 12—18；被动 < 15% | 重写英文 |
| A26 | 中式英语扫描 | C1—C10 扫描记录每类次数 | 改写 |
| A27 | 句式多样性 | 相邻 5 句不出现 ≥3 同开头 | 调整 |
| A28 | 伪正式表达密度 | C4/C9 标记 ≤ 3/百词 | 改写 |
| A29 | 预留 | 未来扩展 | — |
| A30 | TTS 音频质量 | 无爆音截断；专名匹配词典 | 重新配音 |
| A31 | SRT 字幕质量 | 时间偏移达标，专名正确 | 修复字幕 |
| A32 | AI 披露校验 | YouTube 简介含规定声明 | 修改简介 |
| A33 | 前 3 秒钩子兑现 | 0:00—0:03 无引导语，含标题核心词 | Gate 3 重写 |
| A34 | 未闭合环 | 0:05—0:30 有未闭合问题，7:00—8:00 被回应 | Gate 3 重写 |
| A35 | 60—90 秒 re-hook | 每窗口有新信息；连续两窗口无新信息 → FAIL | 重写或拆分 |
| A36 | 代价碎片预置 | 2:30—3:30 有代价/失去的具体人名/物件 | WARN 建议 Gate 3 补充 |
| A37 | 结尾无总结信号 | 无 conclusion/summarize/in the end；End Screen 指向播放列表 | 修改结尾 |

## 人工自检项（H1—H10，必须签字）
| 编号 | 检查项 |
|---|---|
| H1 | 钩子强度（前 30 秒） |
| H2 | 代价段重写质量 |
| H3 | 地图关键帧（逐帧核对） |
| H4 | 配音关键段试听 |
| H5 | 软字幕最终校对 |
| H6 | 结尾开放问题 |
| H7 | 整体叙事节奏 |
| H8 | 叙事逻辑与价值观人工审查（对照样例库） |
| H9 | 英文脚本母语感（至少 3 处修改标注） |
| H10 | 标题与缩略图综合吸引力（遮住频道名并排看） |

## 执行纪律
- 任何 FAIL 阻止进入人工自检（A1—A37 清零后才能 H1—H10）
- H1—H10 任何一项未签字，QA Skill 阻止发布
- 自检报告随 Git 提交归档
- 模型隔离：自检 A21/A25/A26 使用**模型 B**，与 skill-2 的模型 A 隔离（`.trae/rules/ao-workflow-runner.md` §4）

## 合规价值
自检报告 + H1—H10 签字，是"人类创作投入"证据链最后一环。如果平台质疑模板化生产，A4/A21/A25/H2/H7/H8/H9 可作为人类判断参与的直接证据。
