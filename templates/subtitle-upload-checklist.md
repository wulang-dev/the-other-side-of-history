# SRT 软字幕上传 Checklist
# 第四轮审计 WARN-16 修复
# 发布前最后一步：手动上传 SRT 软字幕到 YouTube Studio

---

## 1. 上传前准备（本地）
- [ ] 配音实测总时长 = SRT 字幕覆盖时长（差 ≤ 2s）
- [ ] SRT 字幕里没有残留内部注释（[claim-001]、[MAP]、[TBD]、Prompt 残留等）
- [ ] SRT 字幕格式正确（每行：序号 / 时间戳 / 字幕文本）
- [ ] SRT 开头首句与配音开头精确对齐（误差 ≤ 0.5s）
- [ ] SRT 结尾末句与配音结尾精确对齐（误差 ≤ 0.5s）
- [ ] SRT 文件路径：`episodes/{slug}/subtitles/voiceover.srt`

## 2. YouTube Studio 上传
1. 打开 Studio → 视频 → 选中 → 字幕 → 添加字幕
2. 语言选 **English**（频道主语言）
3. 轨道选 **默认轨道**（不是"新轨道"）
4. 上传 `voiceover.srt`
5. **不上传中文轨道**（对欧美观众无帮助，可能降低推荐权重）

## 3. 上传后验证（Studio 预览）
- [ ] 播放前 30 秒：字幕出现时机与配音精确同步
- [ ] 播放中间 30 秒：字幕与配音无错位
- [ ] 播放结尾：字幕末句与配音末句同时结束
- [ ] 字幕没有错别字（专有名词首次出现格式正确：`Wu Zetian (empress regnant, 624–705 CE)`）
- [ ] 字幕没有残留 AI 生成痕迹（如"to be continued"、"note:"、"prompt:" 等）
- [ ] 关闭 Studio 自动生成的字幕轨道（只保留我们上传的 SRT）

## 4. 为什么不烧录字幕
烧录字幕会导致：
- SEO 损失（YouTube 无法识别画面里的字幕）
- 重传视频才能改（软字幕可以随时改）
- 画面被占用（影响视觉设计）
